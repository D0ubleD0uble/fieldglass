fieldglass-wasm smoke test

Decodes one GRIB2 message in a Web Worker, colours it twice — once on the CPU through render(), once on the GPU through the shader glslSnippet() exports — and compares a WebGL readPixels of the second against the first. The CPU painter is the oracle; the acceptance rule allows one lookup-table entry at a bin edge and nothing else.

Serve the repository root over HTTP and open /crates/fieldglass-wasm/examples/smoke/. Build the module first with crates/fieldglass-wasm/build.sh web.
